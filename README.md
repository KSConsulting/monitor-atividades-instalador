# Monitor de Atividades — instalador

Programa para Windows que registra **apenas o tempo** de uso das telas de trabalho definidas pela empresa.

## Baixar

**[MonitorAtividades.exe (versão mais nova)](https://github.com/KSConsulting/monitor-atividades-instalador/releases/latest/download/MonitorAtividades.exe)**

## Instalar

1. Baixe e abra o `MonitorAtividades.exe`.
2. Se o Windows avisar "O Windows protegeu o computador": **Mais informações → Executar assim mesmo**.
3. Digite o **código de instalação** fornecido pela empresa (vale 24 horas, uso único).

Um ícone verde aparece ao lado do relógio. Clique nele → **Meu dia** para ver o que foi registrado.

## O que é registrado

- Tempo em cada tela de trabalho autorizada pela empresa
- Tempo em outros aplicativos (só o total, sem identificar quais)
- Tempo ocioso (sem mouse/teclado) e com a tela bloqueada

**Não** são registrados: imagens da tela, teclas digitadas, conteúdo de e-mails ou documentos, títulos de janelas,
sites visitados ou nomes de outros programas.

## Desinstalar

Configurações do Windows → Aplicativos → Monitor de Atividades → Desinstalar. É preciso um
**código de desinstalação**, fornecido pela empresa.
